중2 국어 · 공감하고 조정하는 대화

AI와 공감하고 조정하는 대화
연습하기

칸을 채우면 제미나이에게 보낼 메시지가 완성돼요. 복사해서 제미나이 대화창에 붙여 넣으세요.

활동 순서

  1. 학습지 '대화 상황 설계하기' 2번에 쓴 문장을 아래 칸에 옮겨 써요.
  2. 오른쪽 '복사하기'를 누르고, 제미나이 새 대화창에 붙여 넣어요.
  3. 상대방이 먼저 말을 걸면, 학습지 1라운드에 미리 써 둔 내 말을 보면서 대답해요.
  4. 5번쯤 주고받으면 AI가 스스로 대화를 마무리하고 바로 분석해 줘요. AI의 분석을 보고 학습지 점검표를 채워요.

우리 모둠 상황

모둠원 모두 똑같이 써요. 실제 친구 이름 대신 가명을 써요.

대화 흐름

  1. ①상대의 말 들어 주기공감집중하기, 격려하기
  2. ②상대의 마음 읽어 주기공감요약하기 및 재구성하기, 경험 공유하기
  3. ③원인 분석, 객관적인 상황 전달조정
  4. ④나의 감정 표현, 욕구 표현조정
  5. ⑤구체적인 요청조정

프롬프트 ①

제미나이 열기

      

    

  


  
  

    

      

        

          
          
이번엔 내가 서운한 쪽! AI가 어떻게 마음을 풀어 주는지 지켜봐요.

        

      

      

        
활동 순서

        
    
          
  1. 1라운드를 한 같은 대화창에 붙여 넣어요. 새 창을 열면 AI가 상황을 몰라요.
    2. 
          
  2. 이번에는 내가 서운한 상대방이에요. 너무 쉽게 화해하지 말고, 조금 버텨 봐요.
    3. 
          
  3. AI가 공감하고 조정하는 말을 시범으로 보여 줘요. 어느 말에서 마음이 풀리는지 느껴 보세요.
    4. 
          
  4. 5번쯤 주고받으면 AI가 대화를 마무리하고, 자기가 한 말에 문장마다 어떤 방법인지 표시해 줘요.
    5. 
          
  5. 마음이 풀린 말을 학습지에 옮기고, 내 말투로 바꿔 써요.
    6. 
        

        
AI의 시범을 그대로 베끼면 안 돼요. 내가 친구에게 실제로 말한다면 어떻게 말할지 바꿔 써야 내 대사가 돼요.

      

    

    

      
프롬프트 ②

        

      

      

      

    

  


  
  

    

      

        
        

          
AI가 이상할 때 프롬프트

          
필요한 문장을 복사해서 대화창에 보내요.

        

      

      

      

    

    

      
꼭 지켜요

      
    
        
  1. 실제 친구 이름, 학교 이름, 연락처는 입력하지 않아요.
    2. 
        
  2. 학교폭력, 따돌림, 가정 문제, 연애, 혐오 표현은 다루지 않아요.
    3. 
        
  3. AI의 분석은 참고만 해요. 점검표는 내가 배운 기준으로 판단해요.
    4. 
        
  4. AI가 내 대사를 대신 써 주면 쓰지 말고, 학습지에 쓴 내 말로 대화해요.
