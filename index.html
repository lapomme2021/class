[공감하고 조정하는 대화] AI 대화 연습 도우미

칸을 채우면 제미나이에게 보낼 메시지가 완성돼요. 복사해서 제미나이 대화창에 붙여 넣으세요.

하는 순서

  1. 학습지 '대화 상황 설계하기' 2번에 쓴 문장을 아래 칸에 옮겨 써요.
  2. 오른쪽 '복사하기'를 누르고, 제미나이 새 대화창에 붙여 넣어요.
  3. 상대방이 먼저 말을 걸면, 학습지 1라운드에 미리 써 둔 내 말을 보면서 대답해요.
  4. 5번쯤 주고받으면 AI가 대화를 마무리하고 바로 분석해 줘요. 더 일찍 끝내고 싶으면 끝이라고 입력해요. AI의 분석을 보고 학습지 점검표를 채워요.

우리 모둠 상황

모둠원 모두 똑같이 써요. 실제 친구 이름 대신 가명을 써요.

대화 흐름

공감 먼저, 갈등 조정은 다음! 목표: 공감 반응 2가지 이상, 조정 요소 5가지 모두

  1. ①공감하기: 상대의 말 들어 주기집중하기, 격려하기
  2. ②공감하기: 상대의 마음 읽어 주기요약하기 및 재구성하기, 경험 공유하기
  3. ③원인 분석, 객관적인 상황 전달
  4. ④나의 감정 표현, 욕구 표현
  5. ⑤구체적인 요청

    2. 
          
  2. 이번에는 내가 서운한 상대방이에요. 너무 쉽게 화해하지 말고, 조금 버텨 봐요.
    3. 
          
  3. AI가 공감하고 조정하는 말을 시범으로 보여 줘요. 어느 말에서 마음이 풀리는지 느껴 보세요.
    4. 
          
  4. 5번쯤 주고받으면 AI가 대화를 마무리하고, 자기가 한 말에 문장마다 어떤 방법인지 표시해 줘요. 더 일찍 끝내고 싶으면 끝이라고 입력해요.
    5. 
          
  5. 마음이 풀린 말을 학습지에 옮기고, 내 말투로 바꿔 써요.
    6.
